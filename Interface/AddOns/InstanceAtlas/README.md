# InstanceAtlas v0.6.1

This build uses only the map images re-uploaded for this build. All prior map artwork was cleared from the map texture directory before installing these files.

## Included user-supplied maps
- Blackfathom Deeps (3 floors)
- Shadowfang Keep (4 floors)
- Deadmines (2 floors)
- Wailing Caverns
- Ruins of Lordaeron
- Hall of Thanes
- Ragefire Chasm
- Scarlet Monastery (Graveyard, Library, Armory, Cathedral)
- Razorfen Kraul
- Gnomeregan (4 floors)

Scarlet Monastery floor buttons use the named wings. Other multi-floor maps use numbered floor buttons. Boss portraits and encounter rosters are retained. Boss positions and entry/exit coordinates are not claimed as verified against these newly supplied images.

The M-key override and `/ia` command are retained from the previous build.
